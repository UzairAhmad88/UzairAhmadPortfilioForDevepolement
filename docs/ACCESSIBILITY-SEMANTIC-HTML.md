# Semantic HTML Architecture & Landmark Mapping

## 1. Landmark Architecture
Every page generated by Astro follows a standardized landmark outline defined in `src/layouts/BaseLayout.astro`:

| Landmark | Semantic Tag | Accessible Label / Identifier | Purpose |
| :--- | :--- | :--- | :--- |
| **Skip Navigation** | `<a class="skip-link">` | "Skip to main content" | Direct focus bypass to primary body |
| **Banner** | `<header>` | Site Header | Global brand, navigation links, and theme toggle |
| **Primary Nav** | `<nav>` | `aria-label="Main Navigation"` | Core route links and desktop/mobile menu |
| **Main Landmark** | `<main>` | `id="main-content"` `tabindex="-1"` | Primary page payload and editorial content |
| **Complementary** | `<aside>` | When present (e.g. project sidebar) | Metadata, quick stats, tech stack specs |
| **Contentinfo** | `<footer>` | Site Footer | Colophon, copyright, social links, status |

---

## 2. Heading Hierarchy Enforcement
1. **Single `<h1>` per Route:** Each route provides exactly one descriptive `<h1>` representing the page title or primary entity (e.g., project title, research inquiry, or editorial section).
2. **Strict Descending Order:** `h1` is followed by `h2` sections, and subsections strictly use `h3` and `h4`.
3. **No Styling-Driven Skipped Headings:** Font sizes are decoupled from heading semantics using CSS clamp tokens (`var(--font-size-h2)`, `var(--font-size-body)`).

---

## 3. Native Elements vs ARIA Equivalents
We adhere strictly to WAI-ARIA Rule #1: *If you can use a native HTML element with the semantics and behavior you require already built in, do so instead of re-purposing an element and adding an ARIA role, state or property.*

- **Native `<button>`:** Used for all triggers, toggles, filter chips, copy actions, and drawer toggles.
- **Native `<a href="...">`:** Used for all navigation targets and external links.
- **Native `<dialog>` / Accessible Modals:** Used with proper keyboard focus trapping and `aria-modal="true"`.
- **Native Lists (`<ul>`, `<ol>`, `<li>`):** Used for project cards, tech lists, timeline buckets, and navigation links.
