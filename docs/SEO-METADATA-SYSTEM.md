# SEO Title & Meta Description Generation System

## 1. Title Generation Formula
All titles follow a disciplined editorial pattern:
- **Homepage:** `Uzair Ahmad | Quantitative AI & Product Engineer`
- **Projects:** `[Project Name] — Production System & Case Study | Uzair Ahmad`
- **Research:** `[Research Title] — Quantitative Research Inquiry | Uzair Ahmad`
- **Notes:** `[Note Title] — Engineering Note | Uzair Ahmad`
- **Technology:** `[Technology Name] — Engineering Stack & Architecture | Uzair Ahmad`
- **Error Page:** `404: Page Not Found — Uzair Ahmad`

---

## 2. Meta Description Standards
- **Character Count:** Optimized between 140 and 160 characters.
- **Content Authenticity:** Extracted directly from validated data structures (`project.summary`, `research.abstract`, `note.summary`).
- **No Boilerplate Filler:** Every page provides a distinct, contextual summary of the engineering work described on that page.
