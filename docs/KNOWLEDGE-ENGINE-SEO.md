# Knowledge Engine SEO & Crawl Strategy

## 1. Indexation & Canonical Discipline
- **Static Semantic Markup:** All related entity links are embedded as native `<a href="...">` elements in static HTML, ensuring full search crawler discovery without client JavaScript execution.
- **Controlled Indexation:** Pathways and clusters render on primary canonical URLs (`/knowledge`, `/work/[slug]`, `/research/[slug]`), avoiding thin URL proliferation.
