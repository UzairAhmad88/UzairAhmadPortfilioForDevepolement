# Desktop UX: Wide Layouts, Navigation & Multi-Column Density

## 1. Desktop Layout Structure (1024px – 1920px)

- **Persistent Header**: Sticky pill-shaped header navigation with inline links, active indicator, and `<ThemeToggle />`.
- **Three-Column Grids**: Projects, Research papers, Lab experiments, and Engineering Notes distribute evenly across 3-column CSS Grids with balanced gutters (`var(--space-gutter)`).
- **Interactive Multi-Lens Navigator**: Full side-by-side SVG execution topologies and stage flows for the Signature Interaction.
- **Reading Measure Constraints**: Long-form editorial text (case studies, research findings, notes) is strictly bounded by `--container-reading` (`70ch`) to preserve comfortable eye tracking.
- **Hover Micro-Interactions**: Subtle, non-distracting elevation lifts (`-2px`) and border color transitions on pointer devices.
