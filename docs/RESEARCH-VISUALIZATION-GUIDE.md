# Research Visualization & Mathematical Notation Guide

## Visual Philosophy

In alignment with Phase 07 (Project Visualizations) and Phase 02 (Personal Visual Identity), research visualizations prioritize **clarity, technical accuracy, and editorial restraint** over decorative charts.

---

## 1. Supported Visualization Modalities

1. **Methodology Pipelines:**
   Structured, accessible stage-by-stage cards detailing data flow, transformations, model training, and out-of-sample validation.

2. **Mathematical Notation & Code Blocks:**
   Preformatted, accessible code blocks detailing exact mathematical formulas (e.g. fractional differencing binomial expansions, Gaussian mixture probability densities, and state transition functions).

3. **Controlled Experiment Cards:**
   Structured breakdowns showing objective, controlled variables, observed results, and technical interpretation without decorative noise.

4. **Architecture Topologies (Phase 07 Reuse):**
   Reusing `ProjectVisualization.astro` primitives for multi-agent state graphs, quantitative tensor pipelines, and high-performance server layers.

---

## 2. Truth & Accessibility Constraints

- **No Fake Data Charts:** Never generate decorative SVG line graphs with invented stock curves or fake neural loss trajectories.
- **Accessible Math Representations:** All equations and code blocks include semantic labels and monospace formatting for high screen-reader legibility.
- **Color Discipline:** Status indicators (Confirmed, Active, Inconclusive) use consistent subtle background tints and high contrast text ratios (WCAG AA compliant).
