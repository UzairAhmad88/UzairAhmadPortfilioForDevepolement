# Technical SEO Roadmap

This document outlines the strategic progression of search discoverability across three disciplined tiers: **NOW**, **NEXT**, and **LATER**.

## 1. Roadmap Tiers

### NOW (Completed in Phase 08)
- Complete semantic route audit and canonical URL enforcement across all 17 static pages.
- Centralized Schema.org JSON-LD architecture (`Person`, `WebSite`, `ProfilePage`, `TechArticle`, `SoftwareApplication`, `BreadcrumbList`).
- Zero orphan page architecture with verified bidirectional internal linking matrix.
- Structured XML sitemap and clean robots.txt directives.
- Automated unit testing for canonical generation, metadata length bounds, and schema integrity.

### NEXT (Post-Launch & Mid-Term)
- Connect and verify Google Search Console & Bing Webmaster Tools properties.
- Inspect indexing coverage and confirm zero crawl errors.
- Monitor Core Web Vitals (LCP < 1.2s, CLS = 0, INP < 50ms) in production field data.
- Expand research inquiries with reproducible Jupyter notebook links.

### LATER (Long-Term & Topical Growth)
- Introduce in-depth technical articles on *Purged Cross-Validation in Financial ML* and *State Graph Error Recovery in LLM Multi-Agent Topologies*.
- Evaluate topic cluster performance and organic search discoverability for specialized quantitative developer queries.
