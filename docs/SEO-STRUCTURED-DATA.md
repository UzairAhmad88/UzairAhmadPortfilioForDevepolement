# Structured Data Architecture (JSON-LD & Schema.org)

## 1. Supported Schema.org Entities

| Schema Type | Generated By | Target Page Types | Key Properties |
| :--- | :--- | :--- | :--- |
| **`WebSite`** | `getWebSiteSchema()` | Global Homepage | `@type`, `name`, `url`, `author`, `description` |
| **`Person`** | `getPersonSchema()` | Global / About | `name`, `jobTitle`, `url`, `sameAs` (GitHub, LinkedIn), `knowsAbout` |
| **`ProfilePage`** | `getProfilePageSchema()` | `/about` | `mainEntity` -> `Person` |
| **`BreadcrumbList`**| `getBreadcrumbSchema()` | Section & Detail Pages | `itemListElement` with 1-based sequential `position`, `name`, `item` |
| **`TechArticle`** | `getScholarlyArticleSchema()`| Research & Notes | `headline`, `author`, `citation`, `about`, `publisher` |
| **`SoftwareApplication`**| `getSoftwareApplicationSchema()`| Projects | `name`, `applicationCategory`, `operatingSystem`, `codeRepository` |

---

## 2. Integrity & Validation Standards
1. **Valid JSON-LD Syntax:** Rendered as `<script type="application/ld+json">` inside `SchemaOrg.astro`.
2. **Zero Fictional Claims:** Zero bogus reviews, star ratings, fake products, or artificial pricing fields.
3. **Canonical Alignment:** URLs referenced in structured data precisely match page canonical URLs.
