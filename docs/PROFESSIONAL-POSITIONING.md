# Professional Positioning & Capability Matrix

This document defines the professional positioning, supported technical capabilities, target audiences, and communication principles for Uzair Ahmad's digital portfolio.

## 1. Professional Positioning

Uzair Ahmad is a **Quantitative AI & Product Engineer** operating at the intersection of quantitative finance, machine learning, and full-stack software architecture. He designs and implements predictive models, deterministic multi-agent systems, and robust web applications backed by real empirical code and verified repositories.

The positioning is grounded in **real technical evidence** rather than generic freelancer slogans or agency packaging.

## 3. Supported Capabilities vs. Unsupported Claims

### Verified Capabilities (Supported by Actual Code)
- **Time-Series Analysis & Financial ML**: Fractional differentiation, statistical stationarity testing (ADF/KPSS), volatility regime detection (GMM/HMM).
- **Applied AI & Deterministic Multi-Agent Systems**: Directed state graph orchestration (LangGraph), structured schema validation (Pydantic), tool dispatching.
- **Full-Stack Web Engineering**: Astro static generation, TypeScript, React components, Node.js/Python microservices, responsive semantic HTML.
- **Database & Systems Architecture**: SQL/NoSQL schema modeling, RESTful API design, Docker containerization.

### Prohibited / Unsupported Claims (DO NOT Add)
- DO NOT claim live hedge fund alpha or guaranteed trading profitability.
- DO NOT fabricate corporate agency teams, enterprise Fortune 500 client logos, or fake testimonials.
- DO NOT advertise rigid commercial pricing packages ("Bronze / Silver / Gold").
- DO NOT claim 24/7 instant response guarantees unless continuously managed.

## 4. Communication Principles

- **Direct & Technical**: State problem constraints, technical trade-offs, and deliverable scopes clearly.
- **Calm & Honest**: Distinguish between academic/experimental work and production-deployed systems.
- **Action-Oriented**: Guide the visitor to provide meaningful project or inquiry context in their initial outreach.
