## 2. Mapping Cardinality Rules

- **One-to-One**: Standard pattern where 1 portfolio project maps to 1 GitHub repo and 1 Vercel project.
- **One-to-Many**: Supported for projects with split frontend/backend services or multi-cloud deployments.
- **Many-to-One (Monorepos)**: Permitted with explicit path-level curation mappings.
