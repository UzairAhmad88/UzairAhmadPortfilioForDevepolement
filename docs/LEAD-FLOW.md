# Lead Flow & Inbound Routing

This document defines how inbound inquiries are categorized, classified, and formatted for personal review.

## 1. Inquiry Classification Matrix

```
Inbound Payload
      │
      ▼
[Inquiry Classifier]
      ├─► 'project'       ──► Subject: "[Project Inquiry] {Name} - {Organization}"
      ├─► 'employment'    ──► Subject: "[Role Opportunity] {Name} - {Organization}"
      ├─► 'research'      ──► Subject: "[Research Collaboration] {Name}"
      ├─► 'consulting'    ──► Subject: "[Technical Consulting] {Name}"
      └─► 'general'       ──► Subject: "[General Inquiry] {Name}"
```

## 2. Notification Email Layout

Each notification email generated by the contact infrastructure contains structured plain-text and HTML formatting:

```text
============================================================
INBOUND INQUIRY: {Inquiry Type Upper}
============================================================
From: {Name} <{Email}>
Organization: {Organization or 'N/A'}
Timeline / Stage: {Timeline or 'N/A'}
Timestamp: {ISO 8601 UTC}

MESSAGE:
{Message Body}

------------------------------------------------------------
Reply directly to this email to respond to {Name}.
============================================================
```

## 3. Lead Triage Principles

1. **High-Fit Technical Opportunities**: Prioritized response within 24 business hours.
2. **Ambiguous Scopes**: Follow up with a focused questionnaire requesting specific requirements.
3. **Spam / Automated Pitches**: Filtered out automatically via honeypot and payload validation.
