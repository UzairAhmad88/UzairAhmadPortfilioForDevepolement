# 5-Layer System Architecture

## 1. Architectural Topology

The platform is structured into five distinct, decoupled architectural layers:

```
┌─────────────────────────────────────────────────────────────┐
│ 5. PRESENTATION LAYER (Astro Pages, Components & CSS Tokens)│
│    - /work, /research, /lab, /notes, /technology, /discover │
│    - Scoped Vanilla CSS, Design Tokens, Fluid Subgrid       │
└──────────────────────────────┬──────────────────────────────┘
                               │ Ingests Static HTML / Components
┌──────────────────────────────▼──────────────────────────────┐
│ 4. INTERACTION & DISCOVERY LAYER                            │
│    - Discovery Search Engine (src/lib/discovery/)           │
│    - Signature Multi-Lens Navigator (src/lib/signature/)    │
│    - Knowledge Engine Traversal (src/lib/knowledge/)        │
└──────────────────────────────┬──────────────────────────────┘
                               │ Traverses Relational Indices
┌──────────────────────────────▼──────────────────────────────┐
│ 3. RELATIONAL & KNOWLEDGE GRAPH LAYER                       │
│    - Graph Builder & Validator (src/lib/knowledge/)         │
│    - Timeline Engine (src/lib/timeline/)                    │
│    - Vercel Intelligence Matcher (src/lib/vercel/)          │
└──────────────────────────────┬──────────────────────────────┘
                               │ Normalizes Canonical Models
┌──────────────────────────────▼──────────────────────────────┐
│ 2. CANONICAL CONTENT & DATA LAYER                           │
│    - Typed Entities in src/data/ (projects, research, lab,  │
│      notes, technologies, methodology, artifacts)           │
│    - TypeScript Schemas & Contracts (src/types/)            │
└──────────────────────────────┬──────────────────────────────┘
                               │ Built & Validated
┌──────────────────────────────▼──────────────────────────────┐
│ 1. BUILD, QA & DEPLOYMENT LAYER                             │
│    - Astro 4.16 SSG Compiler & Vite                         │
│    - Node.js Native Test Runner (48 suites, 266 tests)      │
│    - Vercel Edge Network Deployment with Security Headers   │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. Layer Specifications

### Layer 1: Build, QA & Deployment
- **Framework**: Astro 4.16.18 with `output: "static"` compiling to `dist/`.
- **Type Checking**: `@astrojs/check` + TypeScript strict mode (`tsconfig.json`).
- **Testing**: `node:test` + `node:assert` validating data contracts, relational links, and SEO metadata.
- **Edge Deployment**: Static asset hosting on Vercel Edge with zero serverless cold starts.

### Layer 2: Canonical Content & Data
- All entities are pure TypeScript data structures.
- Strict type discrimination prevents schema drift.
- Relational integrity is enforced via typed slug arrays (`relatedProjects`, `relatedLab`, `technologies`).

### Layer 3: Relational & Knowledge Graph
- `graphBuilder.ts` constructs an in-memory graph containing $\ge 30$ nodes and $\ge 50$ edges at build time.
- Validates that zero dangling references exist (`invalidEdgeIds.length === 0`).
- Generates 1-hop and 2-hop neighborhood projections for contextual discovery.

### Layer 4: Interaction & Discovery
- In-memory search index generated by `discoveryEngine.ts` supporting full-text query matching, aliases, and facet filters.
- 6-Lens Engineering Navigator exposes distinct analytical views for projects without page reloads.

### Layer 5: Presentation & Design System
- Semantic HTML5 with accessibility landmarks (`<main>`, `<nav>`, `<article>`, `<aside>`).
- Vanilla CSS Design Tokens defined in `src/styles/variables.css` and `src/styles/utilities.css`.
- CSS Subgrid layout contracts for zero-JS multi-column card alignment.
