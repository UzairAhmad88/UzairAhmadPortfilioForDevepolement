**Platform:** Uzair Ahmad — Personal Engineering & Research Platform

**Status:** Canonical Reference  

---

## 1. Core URL Principles

1. **Lowercase Kebab-Case Only:** All URLs are lowercase with hyphens separating tokens (`/work/market-regime-engine`).
2. **Permanent Slugs:** Once published, slugs are immutable. If content moves, a 301/308 redirect must be established in `vercel.json` or Astro routing.
3. **No Unnecessary Nesting:** Avoid deep URL pyramids (e.g. use `/work/curasphere-hms`, NOT `/work/projects/web/2026/curasphere-hms`).
4. **Canonical Self-Referencing:** Every route generates a clean `<link rel="canonical" href="...">` pointing to the canonical origin without trailing slashes.
