# Project Media & Visual Evidence Strategy

This document defines the guidelines for project diagrams, screenshots, technical visual assets, and image optimization.

---

## 1. Visual Evidence Principles

1. **No Fabricated Screenshots**: Never use stock mockups, AI-generated fake product screens, or generic gradient placeholders.
2. **ASCII & Vector Diagrams First**: Architecture diagrams are constructed using semantic ASCII/monospace text or clean SVG blocks, ensuring instant loading, zero layout shifts, and search indexability.
3. **Responsive Dimension Constraints**: Any future raster screenshots (WebP/AVIF) must include explicit `width`, `height`, and `aspect-ratio` definitions.
4. **Accessible Text Equivalents**: Every visual diagram must be accompanied by a `<figcaption>` or descriptive narrative explanation.
