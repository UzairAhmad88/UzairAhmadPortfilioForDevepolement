## 2. Presentation Level Definitions

- **Level A — Featured Case Study**: Flagship technical systems with multi-layer architectures, rigorous mathematical or agentic modeling, technical decisions with explicit trade-offs, and deep retrospectives (e.g. *Stock Return Prediction*, *Multi-Agent Prospect Intelligence*).
- **Level B — Detailed Project**: End-to-end production software and focused quantitative engines with complete problem-approach-architecture breakdowns (e.g. *CuraSphere HMS*, *Market Regime Engine*).
- **Level C — Standard Project Entry**: Functional business tools and client web platforms with concise summaries and public repository links (e.g. *Restaurant POS*, *Hayatabad Gym*).
- **Level D — Experimental / Archive**: Scoped code experiments and utility scripts preserved in documentation and repository archives.
