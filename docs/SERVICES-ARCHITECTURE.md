# Services & Capabilities Architecture

This document defines the structural architecture, evidence mapping, and conversion flows for the `/services` route.

Every capability listed on `/services` is strictly tethered to verified repository evidence and real research investigations:

## 2. Four-Stage Engineering Process

1. **Scoping & Technical Architecture**: Requirements definition, data contracts, and architectural diagrams prior to implementation.
2. **Iterative Milestone Engineering**: Transparent progression with git-backed milestones and continuous testing.
3. **Production Hardening & Verification**: Accessibility auditing, performance benchmarking, and error-handling hardening.
4. **Documentation & Handoff**: Typed code, API documentation, and clean repository handoff.

## 3. Direct Conversion Architecture

Each capability card provides a contextual action button ("Discuss This Capability" / "Explore Evidence") directing visitors straight to `/contact?type=project` with pre-selected inquiry context.
