# 📝 Signature Interaction Content Guide & Microcopy Standards

## Microcopy & Terminology Guidelines

### 1. Lens Nomenclature
| Lens ID | Display Name | Stage Badge | Query Banner Question |

## Content Integrity Rules
- **No Marketing Fluff:** Avoid adjectives like "cutting-edge", "revolutionary", "best-in-class".
- **Focus on Technical Reality:** Emphasize formal boundaries (e.g. *O(N*K) time complexity*, *zero future data leakage*, *FP32 precision*).
- **Honest Postmortems:** Explicitly state technical compromises and known limitations under the Trade-offs lens.
