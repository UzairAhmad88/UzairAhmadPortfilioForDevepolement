# Open Graph & Social Sharing Metadata

## 1. Open Graph (Facebook / LinkedIn) Protocol
Configured per route in `src/components/seo/SEO.astro`:
- `og:title`: Contextual page title
- `og:description`: Factual page description
- `og:type`: `website`, `article`, or `profile`
- `og:url`: Normalized canonical URL
- `og:site_name`: `Uzair Ahmad`
- `og:locale`: `en_US`
- `og:image`: `https://uzairahmad.vercel.app/images/og/default-og.png` (1200x630px high-resolution banner)
- `og:image:alt`: `Uzair Ahmad - Quantitative AI & Product Engineer`

---

## 2. Twitter / X Cards Protocol
- `twitter:card`: `summary_large_image`
- `twitter:title`: Contextual page title
- `twitter:description`: Factual page description
- `twitter:image`: `https://uzairahmad.vercel.app/images/og/default-og.png`
- `twitter:image:alt`: Descriptive preview text
