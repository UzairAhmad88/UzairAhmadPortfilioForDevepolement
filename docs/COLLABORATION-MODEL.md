# Collaboration Model & Engagement Framework

This document outlines how external parties (founders, engineering teams, hiring managers, researchers) can collaborate with Uzair Ahmad.

## 1. Collaboration Types

```
Collaboration Models
├── 1. Full-Time Engineering / Quantitative Roles
│   └── Employment opportunities in AI engineering, quantitative development, or backend systems.
│
├── 2. Technical Consulting & Product Architecture
│   └── Early-stage system scoping, API design, database schema modeling, and zero-to-one MVP prototyping.
│
├── 3. Applied AI & Machine Learning Pipeline Integration
│   └── Designing deterministic state graphs for LLM workflows, feature extraction pipelines, and model evaluation.
│
└── 4. Research Collaboration & Open-Source Development
    └── Joint empirical inquiries in non-stationary time series, financial volatility modeling, or agentic frameworks.
```

## 2. Inbound Inquiry Workflow

```
1. Visitor Discovers Work / Research
   └── Navigates via project case studies or research lab.
2. Contextual Outreach
   └── Selects specific inquiry type (Project, Employment, Research, General).
3. Structured Intake
   └── Visitor provides scope, technical context, timeline, or job description.
4. Review & Triage
   └── Direct evaluation of technical alignment, feasibility, and calendar bandwidth.
5. Technical Alignment Call or Async Response
   └── Clear next steps or polite referral if out of scope.
```

## 3. Mutual Expectations

### What Uzair Brings:
- Production-grade code with strict typing and documentation.
- Empirical grounding with explicit trade-off analyses.
- Clear, respectful, and transparent async communication.

### What Inquirers Should Provide:
- **For Projects**: High-level problem statement, target deliverables, and desired timeline.
- **For Roles**: Role title, scope, compensation range / model, and tech stack.
- **For Research**: Specific paper, dataset, or mathematical question of interest.
